텔레그램 API 값을 넣어주세요

텔레그램이 발급해주는 두 개의 값입니다. 아직 없으면 아래 안내를 펼쳐 3분 안에 받아올 수 있습니다.

텔레그램 API

두 값 모두 같은 페이지에서 함께 나옵니다
발급 방법 보기
  1. my.telegram.org 를 새 탭에서 엽니다.
  2. 전화번호를 넣으면 텔레그램 앱으로 확인 코드가 옵니다. 문자(SMS)가 아니라 앱 안의 Telegram 대화에 옵니다.
  3. 로그인하면 API development tools 를 누릅니다.
  4. 앱 이름과 짧은 이름을 아무렇게나 적습니다. (예: telepulse) 나머지는 비워도 됩니다.
  5. 만들면 App api_id 와 App api_hash 가 나옵니다. 이 두 개를 위에 붙여넣으세요.
주의 — 코드를 두 번 받습니다. 방금 my.telegram.org 로그인에 쓴 코드와, 다음 단계에서 이 프로그램이 요청할 인증코드는 서로 다른 코드입니다. 다음 단계에서 새 코드가 오면 그것을 쓰세요.

텔레그램에 로그인하세요

어떤 방을 구독 중인지 읽어오기 위해 본인 계정으로 한 번 로그인합니다. 봇이 아니라 본인 계정이어야 구독 목록을 볼 수 있습니다.

국가번호를 포함해서 입력하세요. 텔레그램에 가입한 번호여야 합니다.

이 로그인으로 무엇을 하나

읽기만 합니다. 방 목록과 메시지를 읽고, 완성된 브리핑을 본인의 '저장된 메시지'로 보냅니다. 남에게 메시지를 보내지 않고 방에 글을 쓰지 않습니다.

로그인 정보는 본인의 GitHub 비공개 저장소에만 저장됩니다. 만든 사람도 볼 수 없습니다.

인증코드를 넣어주세요

텔레그램 앱으로 5자리 코드를 보냈습니다. 문자(SMS)가 아니라 텔레그램 앱 안의 Telegram 계정 대화에 옵니다.

텔레그램에 2단계 인증을 켜두신 경우에만 입력하세요.

마지막 — OpenAI 키

붙여넣으면 실제로 연결해 유효한 키인지 확인합니다. (확인은 무료입니다)

발급 방법 보기
  1. platform.openai.com 을 새 탭에서 엽니다. 계정이 없으면 가입합니다. (ChatGPT 계정과 별개일 수 있습니다)
  2. Billing 에서 결제 카드를 먼저 등록합니다. 카드가 없으면 키를 만들어도 작동하지 않습니다.
  3. API keys → Create new secret key
  4. sk- 로 시작하는 값을 복사해 위에 붙여넣습니다.
키는 한 번만 보입니다. 창을 닫으면 다시 볼 수 없고 새로 만들어야 합니다. 만든 즉시 복사하세요.
화면 구성이 안내와 다르면 왼쪽 메뉴나 우측 상단 설정에서 API keys 를 찾으세요 — OpenAI는 화면을 자주 바꿉니다.
